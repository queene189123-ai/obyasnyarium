# Перед релизом Объясняриума

## Состояние на 21 октября 2026

- GitHub Pages: проверка публикации прошла, адрес проекта отвечает HTTP 200 и содержит реальный `index.html`.
- Онлайн-регрессия: тест двух независимых браузеров прошёл; проверены создание/вход, синхронизация, восстановление соединения и сессии, начисление очков, реванш, выход игрока, защита токенов, ограничение 20 игроков и мобильный офлайн-режим.
- Собственный домен: пока не подтверждён. Последняя проверка с runner GitHub не смогла разрешить `obyasnyarium.ru` в DNS (`Could not resolve host`). Не возвращать `CNAME` в публикацию и не включать HTTPS для домена, пока DNS не резолвится и GitHub Pages не подтвердит его.
- Рекламные блоки: не включены; см. `MONETIZATION.md`.
- Supabase: онлайн API работает в регрессионном тесте. В SECURITY DEFINER RPC намеренно разрешён `anon`, потому что игра не требует регистрации; доступ защищён токенами игроков и проверками состояния. Не отзывать EXECUTE у `anon` без отдельного изменения клиентской архитектуры.

## Важное замечание о миграциях Supabase

История production-проекта содержит версии `20261021111317`, `20261021113905`, `20261021122330`, `20261021122839`, `20261021122954`, `20261021123118`, `20261021123357`, `20261021123834`, `20261021150133`. Имена/версии части SQL-файлов в репозитории не совпадают с этой историей, а несколько production-миграций отсутствуют в папке. Поэтому **не запускать `supabase db push`, `supabase db reset` или автоматическое применение всех файлов из `supabase/migrations`**, пока не будет восстановлена точная история миграций и проверена на отдельной базе. Это не мешает текущему сайту: тесты используют уже работающий production API и не применяют миграции.

## Порядок включения собственного домена

1. В DNS-панели домена убедиться, что корневой домен имеет четыре A-записи GitHub Pages: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
2. Для `www` использовать CNAME на `queene189123-ai.github.io`.
3. Не менять NS-серверы, если домен уже обслуживается DNS Beget и записи редактируются там; не удалять почтовые/служебные поддомены.
4. Дождаться, пока корневой домен и `www` разрешаются в DNS извне.
5. В настройках GitHub Pages указать `obyasnyarium.ru`; только после успешной проверки домена включить Enforce HTTPS.
6. Вернуть в корень репозитория файл `CNAME` с единственной строкой `obyasnyarium.ru` только после проверки корректной настройки Pages, затем проверить обе версии домена и редиректы.
7. Запустить два браузера на разных профилях/устройствах и пройти полный онлайн-ход.

## Релизные запреты

- Не менять дизайн/игровую логику ради рекламы.
- Не помещать рекламу на активные игровые экраны.
- Не публиковать service-role ключи Supabase и другие секреты в `index.html`.
- Не удалять комнаты или данные production без явного решения владельца.
- После изменений в `index.html`, SQL-миграциях или тестах проверять соответствующий GitHub Actions workflow.
